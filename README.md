# Alquilando


**Alquilando** es una plataforma web para gestionar alquileres temporarios. Permite a administradores publicar inmuebles, gestionar reservas, disponibilidad y comunicarse con clientes, quienes pueden realizar sus reservas online. Además, los encargados pueden administrar las propiedades que tienen asignadas, facilitando la gestión diaria.

## Proyecto Académico

Este proyecto fue desarrollado como trabajo práctico para la materia **Ingeniería de Software II** de la **Facultad de Informática - Universidad Nacional de La Plata (UNLP)**.
